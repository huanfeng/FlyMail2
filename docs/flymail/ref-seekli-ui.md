# 参考产品分析：seek.li（NodeSeek 邮箱）

> 2026-10-16 通过远程 Chrome（CDP）实地走查，桌面 1440×765、平板 1024、手机 390 三档。
> 全程只读：未发信、未删改、未改设置；只打开了已读邮件。
> 目的：提炼它「基本操作设计」的优点，对照 FlyMail 找可借鉴项。

## 一、整体结构

- **经典三栏**：侧栏（账户/文件夹/标签）｜列表｜阅读区。列表栏宽固定约 360px，阅读区吃掉剩余宽度。
- **邮件工作区与管理后台分离**：齿轮进入 `/manage/*` 独立路由，左侧换成「账号设置 / 邮箱管理 / 邮件管理 / 知识林 / 数据统计 / 操作日志 / 开发者 API / 帮助与支持」；
  侧栏顶部「←」返回邮件。日常收发与低频配置完全不在同一个界面里打架。
- **账户切换是一个下拉**（侧栏顶部），首项「全部邮箱」聚合视图，每个邮箱带未读红点，底部「管理分组与排序」。
  侧栏下方的文件夹树因此永远只有一套，不随邮箱数量膨胀。

## 二、它做得好的操作设计（按价值排序）

### 1. 列表行：悬停即操作，时间位让位
- 行悬停时，右上角的相对时间淡出，**原位**换成 4 个图标：归档 / 删除 / 标为已读 / 旗标。
  不额外占宽度，不挤压主题行，也不会因为常驻图标让列表变花。
- 勾选框同样只在悬停时出现在行首；一旦有勾选，所有行的勾选框常显，列表头变成
  「已选 2 封 + 已读/未读/归档/删除」批量条——**批量条就地替换列表头**，不弹浮层。
- 全选框旁的小箭头给「全部 / 无 / 已读 / 未读 / 已加旗标 / 未加旗标」按条件选择（Gmail 同款）。
- 列表头有「全部 | 未读」分段切换，一键只看未读。
- 发件人名后紧跟**认证盾牌**（SPF+DKIM+DMARC 全过才显示绿色），未读用名字后的小圆点而非整行加粗变色。

### 2. 阅读区工具条：纯图标 + 分组分隔
- 顶部一排纯图标：稍后提醒 · 提醒 · 归档 · 删除(红) ｜ 移动 · 星标 · 已读未读 ｜ ⋯；右侧 专注阅读 · 关闭。
- 主动作（回复/转发）**下沉到阅读区底部的固定动作条**：回复（实心主按钮）、转发、举报、快捷回复(⚡)、种入知识林。
  顶部管「处置这封信」，底部管「回应这封信」，两类动作分区清楚。
- 「⋯」里放低频项：添加标签、加入白名单、标为垃圾、查看原始邮件、下载 .eml。

### 3. 快捷回复（⚡）
- 点击后在底部动作条下方展开一个内联文本框，「Ctrl+Enter 发送」提示 + 取消/发送，
  **不打开完整撰写窗口**。简短回应的成本降到最低。

### 4. 信任与安全信息分层
- 发件人地址旁一个「已认证 (3/3)」绿胶囊，展开看 SPF/DKIM/DMARC 各项与「安全发件人 / 已认证寄件者」。
- 其下一条「安全评估 · 低风险 0/100」可折叠横条，展开有认证风险/规则风险分项。
- 远程图片默认屏蔽，黄色提示条 + 「加载远程内容」按钮。
- 默认状态都是**一行**，需要时才展开——信息很多但不压正文。

### 5. 稍后提醒与提醒：预设 + 具体时间
- 「稍后提醒」是对话框：3 小时后 / 明天 09:00 / 下周一 09:00，**每项右侧标出换算后的具体时间**（10/16 15:52），
  另有自定义时间。用户不必心算「下周一是几号」。
- 「提醒」是下拉：30 分钟 / 1 小时 / 3 小时 / 明天上午 9:00 + 自定义。

### 6. 撰写器：不能发送时说清原因
- 发送按钮置灰时，底部常驻一条提示：「当前还不能发送：当前发件邮箱所在域名已禁止发信；请输入收件人」——
  **把所有阻塞条件列出来**，并在发件人下方就地给「申请临时发信权限」入口。
- 抄送/密送默认折叠为「+抄送 +密送」，签名与模板也折叠。

### 7. 外观设置：分组 + 实时预览 + 统一保存
- 「外观工作室」分 主题 / 工作区 / 阅读 / 高级 四页；右侧常驻**迷你三栏实时预览**；
  底部固定保存条「所有改动均已保存 · 恢复默认 / 放弃改动 / 保存」。
- 工作区可调：列表密度（紧凑/舒适/宽松）、字体风格、圆角规模、动效强度、字号倍率、链接下划线；
  **栏宽只保存在本设备**（避免宽屏设置污染手机）。
- 阅读页专门调「邮件正文」：最小字号、最小行高、阅读宽度（原始/舒适/宽）、自动增强低对比度文字、本机正文缩放。
  界面字号与正文字号是两套独立设置——这个区分很专业。

### 8. 响应式
- 1024：侧栏收进汉堡菜单，列表 + 阅读双栏，悬停动作仍可用。
- 390：单栏；列表头的勾选框换成「进入选择模式」按钮（触屏无悬停）；聚合视图下每行多一个邮箱胶囊（code3）；
  阅读页顶部「‹ 返回列表」，底部动作条保留。

## 三、不建议照搬 / 它自己的问题

| 问题 | 观察 | 对 FlyMail 的意义 |
|---|---|---|
| 主色不统一 | 稍后提醒「保存」是蓝、提醒「确定」是紫、加载远程是橙、主按钮是近黑 | FlyMail 坚持单一 primary 令牌，别学 |
| 图标按钮无可访问名称 | 阅读区顶部 7 个图标按钮读不到 aria-label，悬停也无 tooltip（只有专注阅读有） | 纯图标模式必须配 tooltip + aria-label，FlyMail 已做 |
| Esc 层级过冲 | 专注阅读中按 Esc，同时退出专注**并关闭邮件**；账户下拉打开时 Esc 不关闭 | FlyMail 第八轮刚修过同类问题（一次 Esc 只退一层） |
| 无右键菜单 | 列表行右键无反应 | FlyMail 已有，保留 |
| 手机阅读页重复出口 | 「返回列表」与右上「×」同时出现 | 二选一即可 |
| 快捷键较少 | 仅 j/k/Esc/c/r/a/d/e/s/? | FlyMail 已更全（g 前缀跳转、x 选择、# 删除、/ 搜索、u 返回） |

## 四、对 FlyMail 的借鉴清单（建议优先级）

| 优先级 | 借鉴项 | FlyMail 现状 |
|---|---|---|
| P0 | 列表行悬停：时间位原位替换为 归档/删除/已读/星标 四个动作 | 仅有 hover 删除 + 星标 |
| P0 | 勾选后列表头就地变批量条；全选旁按条件选择（已读/未读/星标） | 有批量操作，形态待对照 |
| P1 | 阅读区「顶部处置、底部回应」的动作分区；底部固定回复/转发条 | 工具条集中在顶部 |
| P1 | 快捷回复：内联文本框 + Ctrl+Enter，不开完整撰写器 | 无 |
| P1 | 撰写器发送按钮置灰时列出全部阻塞原因 | 待核对 |
| P1 | 列表头「全部 / 未读」分段切换 | 待核对 |
| P2 | 稍后提醒（snooze）：预设项带换算后的具体时间 | 无 snooze |
| P2 | 发件人认证胶囊（SPF/DKIM/DMARC）+ 可折叠风险条 | 后端有认证结果字段，前端未展示 |
| P2 | 正文阅读设置独立于界面字号：最小字号/行高/阅读宽度/低对比增强/本机缩放 | 有阅读设置页，项较少 |
| P2 | 外观设置右侧实时预览 + 底部统一保存条 | 即改即存 |
| P3 | 专注阅读（阅读区全屏，隐藏侧栏和列表） | 无 |
| P3 | 栏宽仅存本设备 | 待核对 |
