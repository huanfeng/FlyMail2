## Project Configuration

- 包管理器使用 pnpm
- 不要自己运行 pnpm dev
- TypeScript 代码尽量描述完整的类型, 以提高可维护性
- 在添加功能时先思考一下当前技术栈的最佳实践, 如果仍然不清楚该怎么做, 请先进行提问
- 在添加页面功能时, 如果需要使用文本, 请使用 i18n 处理多语言部分
- 在修改 json 的语言文本时, 注意不要有重复的 key, 注意不要出现引号内嵌的情况, 修改完后请使用工具验证其格式正确

交互原则
- 总是以中文回复
- 需要明确需求后才开始工作, 有任何不清楚的地方先进行提问

Git 操作规范
- 除非我明确指示, 否则不要自行提交 git 记录
