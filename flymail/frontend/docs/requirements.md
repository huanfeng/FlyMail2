# FlyMailPlus 前端需求文档

## 项目概述
基于 Vue + Vite + Shadcn-ui-vue + TypeScript 构建的邮件客户端前端应用。

## 技术栈
- **框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **UI 组件库**: Shadcn-ui-vue
- **路由**: Vue Router (Hash 模式)
- **状态管理**: Pinia (推荐)

## 功能需求

### 1. 整体布局
- **布局方式**: 三栏布局（参考 Shadcn Email 模板）
  - 左栏：账户列表和文件夹树
  - 中栏：邮件列表
  - 右栏：邮件详情
- **响应式设计**: 支持桌面端和移动端适配
- **可调整宽度**: 三栏之间支持拖拽调整宽度

### 2. 账户管理
- **多账户支持**: 树形结构展示多个邮件账户
- **账户切换**: 支持快速切换不同账户
- **虚拟文件夹**: 
  - 所有收件箱
  - 所有未读
  - 所有星标
  - 所有草稿箱
  - 所有已发送
  - 所有垃圾箱
- **折叠功能**: 账户和文件夹支持展开/折叠

### 3. 用户中心
- **位置**: 左栏顶部
- **内容**: 
  - 用户头像
  - 用户名称
  - 邮箱地址
  - 设置入口按钮

### 4. 设置功能
- **展示方式**: 弹窗模式
- **布局**: 左右分栏
  - 左侧：设置分类菜单
  - 右侧：具体设置项
- **设置项**:
  - 账户管理（添加/删除/编辑账户）
  - 通用设置（主题、语言、字体等）
  - 邮件设置（签名、自动回复等）
  - 安全设置（密码、两步验证等）
  - 通知设置

### 5. 邮件列表功能
- 邮件预览（发件人、主题、时间、摘要）
- 批量操作（全选、标记已读/未读、删除等）
- 搜索功能
- 排序功能（时间、发件人、主题等）
- 分页或虚拟滚动

### 6. 邮件详情功能
- 完整邮件内容展示
- 附件查看和下载
- 回复、全部回复、转发
- 标记（星标、标签等）
- 移动到文件夹

### 7. 编写邮件功能
- 富文本编辑器
- 附件上传
- 收件人自动补全
- 草稿自动保存
- 发送定时功能

## 设计规范
- 遵循 Shadcn-ui 设计语言
- 支持亮色/暗色主题切换
- 保持界面简洁、现代化
- 注重用户体验和交互流畅性

## 性能要求
- 首屏加载时间 < 3秒
- 邮件列表支持虚拟滚动
- 图片和附件懒加载
- 合理的缓存策略

## 兼容性
- 现代浏览器（Chrome、Firefox、Safari、Edge 最新版本）
- 移动端浏览器适配
- 响应式断点：
  - 移动端：< 768px
  - 平板端：768px - 1024px
  - 桌面端：> 1024px
